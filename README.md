# MySSH Usage

Connect to a remote computer via SSH:

```bash
In Windows CMD or PowerShell
```

```bash
myssh ssh-connect <username> <ip-address>
```

Example:

```bash
myssh ssh-connect maher ipv4
```

or with IPv6:

```bash
myssh ssh-connect maher ipv6
```

Enter the password when requested.

After connecting, you can run commands on the remote computer.
